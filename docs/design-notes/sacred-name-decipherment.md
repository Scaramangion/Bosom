When people say a name like the Tetragrammaton (יהוה / YHWH) is "lost," it isn't because we have no idea how ancient Semitic languages worked. Rather, ancient Hebrew was written using an abjad (a writing system that only records consonants, leaving vowels unwritten). The original pronunciation became hidden over centuries because reading traditions substituted words like Adonai ("Lord") or Elohim ("God") out of reverence, causing the original vocalization to fade from living oral tradition.
A specialized computational philologist model can reconstruct how "lost" words and sacred names were pronounced by applying the exact methodology historical linguists use today.
